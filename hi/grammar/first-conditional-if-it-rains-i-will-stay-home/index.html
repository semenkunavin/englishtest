First Conditional: If it rains, I will stay home (A2 हिंदी में)

First Conditional future की उन बातों के लिए use होता है जो पक्की नहीं हैं, पर possible हैं — जैसे job interview में planning या daily conversation में। Formula है: If + present simple, will + verb. यानी condition पहले, result बाद में।

  1. Structure: If + present simple, subject + will + base verb. Example: If Priya calls, I will answer.
  2. If वाले part में will कभी नहीं आता: If it rains सही है, If it will rain ग़लत।
  3. दोनों parts की position बदल सकती है: I will stay home if it rains. — comma तब हट जाता है जब If वाला part बाद में आए।
  4. will के साथ हमेशा base verb: will go, will call, will prepare — will goes नहीं।
  5. Condition real और possible होनी चाहिए — future plan, warning, promise या offer के लिए use करें।
  6. Short form spoken English में common है: I'll, she'll, we'll — जैसे If I get the job, I'll join on Monday.

Examples

  • If it rains tomorrow, I will stay home.अगर कल बारिश होगी, तो मैं घर पर रहूँगा।
  • If Rahul practises daily, he will speak English confidently.अगर राहुल रोज़ practice करेगा, तो वह confident तरीके से English बोलेगा।
  • If you reach the office late, the manager will ask questions.अगर तुम office late पहुँचोगे, तो manager सवाल पूछेगा।
  • I will call you if the interview time changes.अगर interview का time बदलेगा, तो मैं तुम्हें call करूँगा।
  • If Anjali gets this job in Pune, she will move there next month.अगर अंजलि को Pune में यह job मिलेगी, तो वह अगले महीने वहाँ shift हो जाएगी।
  • If we finish the project today, we will start the next one on Monday.अगर हम आज project ख़त्म करेंगे, तो हम अगला Monday से शुरू करेंगे।

आम गलतियाँ

If it will rain, I will stay home.
If it rains, I will stay home.
If के बाद will नहीं आता; present simple rains use करें।
If I will get the job, I will tell you.
If I get the job, I will tell you.
Condition वाले part में get (present simple) आएगा, will get नहीं।
If she calls, I will goes to meet her.
If she calls, I will go to meet her.
will के बाद हमेशा base verb go आता है, goes नहीं।
