Zero Conditional (If you heat ice, it melts) - सीखें आसान हिंदी में

Zero conditional का इस्तेमाल उन बातों के लिए होता है जो हमेशा सच होती हैं, जैसे scientific facts, general truths, या habitual actions। इसमें if वाला part और main clause दोनों present tense में होते हैं। Job interview में अपनी skills बताते समय या रोज़मर्रा की बातचीत में यह बहुत काम आता है।

  1. Structure: If + present simple, present simple. दोनों clauses में present tense आता है।
  2. Fact या general truth बताने के लिए use करें, जैसे If you heat ice, it melts.
  3. Habit या routine बताने के लिए भी use करें, जैसे If I drink coffee, I feel energetic.
  4. If की जगह when भी use कर सकते हैं, meaning लगभग same रहता है।
  5. Main clause में will या would नहीं आता; दोनों जगह present simple ही रखें।
  6. Comma का use तब करें जब if clause पहले आए; अगर main clause पहले है तो comma की जरूरत नहीं।

Examples

  • If you heat ice, it melts.अगर आप बर्फ को गर्म करते हैं, तो वह पिघल जाती है।
  • If Ramesh practices English daily, he speaks confidently.अगर रमेश रोज़ English practice करता है, तो वह confidently बोलता है।
  • Plants die if they don't get water.पौधे मर जाते हैं अगर उन्हें पानी नहीं मिलता।
  • If you press this button, the machine starts.अगर आप यह बटन दबाते हैं, तो मशीन चालू हो जाती है।
  • Priya gets good marks if she studies regularly.प्रिया अच्छे marks लाती है अगर वह नियमित पढ़ती है।
  • If it rains, the roads become slippery in Mumbai.अगर बारिश होती है, तो मुंबई में सड़कें फिसलन भरी हो जाती हैं।

आम गलतियाँ

If you heat ice, it will melt.
If you heat ice, it melts.
Zero conditional में main clause में will नहीं आता; present simple use करें।
If I will study hard, I get good marks.
If I study hard, I get good marks.
If clause में will नहीं आता; present simple रखें।
