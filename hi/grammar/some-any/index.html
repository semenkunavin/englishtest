Some / Any in English: आसान Hindi Explanation (A1)

Some और any दोनों का मतलब होता है "कुछ" या "थोड़ा", लेकिन इनका use sentence के type पर depend करता है। Affirmative (positive) sentences में usually some आता है, और negative sentences तथा questions में any आता है। Interview में जब आप अपने experience या skills के बारे में बोलते हैं, तो ये words बहुत common हैं — इसलिए इन्हें clear करना ज़रूरी है।

  1. Positive (affirmative) sentence में some use करें: I have some questions.
  2. Negative sentence में any use करें: I don't have any experience in sales.
  3. Question में usually any आता है: Do you have any doubts?
  4. Offer या request में some use होता है, चाहे sentence question हो: Would you like some tea?
  5. Some और any के बाद countable noun का plural (some files) या uncountable noun (some water) आता है।
  6. एक singular countable noun के साथ some/any नहीं आता — वहाँ a या an use करें: I need a pen (not: some pen).

Examples

  • I have some questions about the job profile.मेरे पास job profile के बारे में कुछ सवाल हैं।
  • She doesn't have any experience with Excel.उसके पास Excel का कोई experience नहीं है।
  • Do you have any friends in Bengaluru?क्या बेंगलुरु में तुम्हारे कोई दोस्त हैं?
  • Would you like some water before the interview?Interview से पहले कुछ पानी पिएंगे?
  • We need some time to prepare for the group discussion.Group discussion की तैयारी के लिए हमें कुछ time चाहिए।
  • Rahul didn't ask any questions in the meeting.राहुल ने meeting में कोई सवाल नहीं पूछा।

आम गलतियाँ

I don't have some experience.
I don't have any experience.
Negative sentence में any आता है, some नहीं।
Do you have some questions?
Do you have any questions?
Normal question में any use करें; some सिर्फ offer/request में।
I need some pen for the interview.
I need a pen for the interview.
एक singular countable noun से पहले a आता है, some नहीं।
