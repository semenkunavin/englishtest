कपड़े खरीदना in English: phrases और sample dialogue

ये phrases तब काम आएंगे जब आप कपड़े खरीदने shop जाएं, size या colour पूछें, try करें या कोई item return करना हो। Job interview और career के लिए spoken English में confident बनने के लिए ये रोज़मर्रा के phrases बहुत useful हैं।

काम के वाक्यांश

  • Can I help you?क्या मैं आपकी मदद कर सकता हूँ?
  • I'm just looking, thanks.मैं बस देख रहा हूँ, धन्यवाद।
  • Do you have this in a medium?क्या यह medium size में है?
  • What size is this?यह कौन सा size है?
  • Can I try it on?क्या मैं इसे try कर सकता हूँ?
  • Where is the fitting room?fitting room कहाँ है?
  • It's too tight.यह बहुत tight है।
  • It's a bit loose.यह थोड़ा loose है।
  • Do you have this in another colour?क्या यह किसी और colour में है?
  • I'd like a blue one.मुझे blue रंग वाला चाहिए।
  • How much is it?इसकी कीमत क्या है?
  • I'll take it.मैं इसे ले लूँगा।
  • Can I pay by card?क्या मैं card से pay कर सकता हूँ?
  • Can I return it if it doesn't fit?अगर यह fit नहीं हुआ तो क्या मैं return कर सकता हूँ?
  • What is the return policy?return policy क्या है?
  • I'd like to return this shirt.मैं यह shirt return करना चाहता हूँ।
  • Do you have the receipt?क्या आपके पास receipt है?
  • Can I exchange it for a larger size?क्या मैं इसे बड़े size से exchange कर सकता हूँ?
  • It doesn't fit me.यह मुझे fit नहीं आया।
  • Thank you for your help.आपकी मदद के लिए धन्यवाद।

नमूना बातचीत

  • सामने वाला: Hello! Can I help you?नमस्ते! क्या मैं आपकी मदद कर सकता हूँ?
  • आप: Yes, I'm looking for a formal shirt for my interview.हाँ, मैं अपने interview के लिए formal shirt ढूंढ रहा हूँ।
  • सामने वाला: What size do you wear?आप कौन सा size पहनते हैं?
  • आप: Medium, please. Do you have this in blue?Medium, please। क्या यह blue में है?
  • सामने वाला: Yes, here you go. The fitting room is over there.हाँ, यह लीजिए। fitting room वहाँ है।
  • आप: Thanks. (after trying) It's a bit tight. Can I try a large?धन्यवाद। (try करने के बाद) यह थोड़ा tight है। क्या मैं large try कर सकता हूँ?
  • सामने वाला: Sure, here is a large. How is it?ज़रूर, यह large है। कैसा लगा?
  • आप: It fits well. I'll take it. How much is it?यह अच्छा fit है। मैं इसे ले लूँगा। इसकी कीमत क्या है?
  • सामने वाला: It's 799 rupees. Can I pay by card?यह 799 रुपये है। क्या मैं card से pay कर सकता हूँ?
  • आप: Yes, sure. And what is the return policy?हाँ, ज़रूर। और return policy क्या है?
  • सामने वाला: You can return it within 15 days with the receipt.आप receipt के साथ 15 दिनों में return कर सकते हैं।
  • आप: Great, thank you!बहुत अच्छा, धन्यवाद!

आम गलतियाँ

I want to try this shirt.
Can I try this shirt on?
दुकान में विनम्रता से पूछना बेहतर है। 'try on' phrase use करें, सिर्फ 'try' नहीं।
This is too much tight.
This is too tight.
'tight' के साथ 'much' नहीं लगाते। सीधे 'too tight' कहें।
I want return this.
I'd like to return this.
'want' के बाद 'to' लगता है, और दुकान में 'I'd like to' ज़्यादा polite है।

टिप

जब भी कपड़े try करें, fitting room में जाकर ज़रूर देखें कि आप ठीक से move कर पा रहे हैं या नहीं। अगर size fit न हो तो विनम्रता से 'Can I try a different size?' पूछें। इससे आपकी spoken English practice भी होगी और confidence बढ़ेगा।
