Some e any em inglês: regras simples para o dia a dia

Você usa some e any para falar de quantidades indefinidas, sem dizer o número exato: alguns, algumas, um pouco de. Em geral, some aparece em frases afirmativas e any em negativas e perguntas. É essencial no trabalho, em e-mails e em viagens, como pedir informações num hotel em Recife ou comprar material para a equipe em São Paulo.

  1. Use some em frases afirmativas com substantivos plural ou incontáveis: I have some questions.
  2. Use any em frases negativas: We don't have any coffee.
  3. Use any em perguntas: Do you have any change?
  4. Use some em ofertas e pedidos, mesmo em perguntas: Would you like some water? / Can I have some help?
  5. Use some ou any sem artigo antes do substantivo: some information, nunca some an information.
  6. Com substantivos incontáveis (water, money, information), some e any significam “um pouco de”; com plurais (tickets, emails), significam “alguns/algumas”.

Exemplos

  • I need some information about flights to Salvador.Eu preciso de algumas informações sobre voos para Salvador.
  • We don't have any meetings on Friday.Não temos nenhuma reunião na sexta-feira.
  • Do you have any questions about the project?Você tem alguma pergunta sobre o projeto?
  • Would you like some coffee before the meeting?Você gostaria de um pouco de café antes da reunião?
  • There are some tickets for the conference in Curitiba.Há alguns ingressos para a conferência em Curitiba.
  • She didn't send any emails yesterday.Ela não enviou nenhum e-mail ontem.

Erros típicos

I don't have some money for the taxi.
I don't have any money for the taxi.
Em frases negativas usamos any, não some.
Do you have some questions?
Do you have any questions?
Em perguntas normais usamos any; some fica para ofertas e pedidos.
Can I have any water, please?
Can I have some water, please?
Em pedidos usamos some, mesmo sendo uma pergunta.
