Would like em inglês: I'd like a coffee (nível A1)

Usamos would like para pedir ou dizer o que queremos de forma educada, como num café, num hotel ou numa entrevista de trabalho. A forma curta é 'd like: I'd like a coffee = eu queria um café. É a versão mais educada de want e você vai usá-la muito em viagens e no trabalho.

  1. Para pedir algo: I'd like + substantivo. Ex.: I'd like a coffee, please.
  2. Para dizer o que quer fazer: I'd like to + verbo. Ex.: I'd like to visit São Paulo.
  3. Para perguntar: Would you like...? Ex.: Would you like some water?
  4. Use some com plural e incontáveis (some water, some apples) e a/an com singular contável (a coffee, an apple).
  5. A forma curta de would é 'd: I'd like, she'd like. Não diga I would like a coffee em conversa informal — é correto, mas mais formal.
  6. Would like é mais educado que want. Em lojas, restaurantes e hotéis, prefira I'd like.

Exemplos

  • I'd like a coffee, please.Eu queria um café, por favor.
  • Would you like some water, Ana?Você quer um pouco de água, Ana?
  • I'd like to book a room for two nights.Eu gostaria de reservar um quarto para duas noites.
  • Rafael would like to work in London next year.O Rafael gostaria de trabalhar em Londres no ano que vem.
  • Would you like a receipt?Você gostaria de um recibo?
  • We'd like to visit Salvador in July.Nós gostaríamos de visitar Salvador em julho.

Erros típicos

I like a coffee, please.
I'd like a coffee, please.
Sem o 'd, I like significa "eu gosto". Para pedir, use I'd like.
I'd like to a coffee.
I'd like a coffee.
to só aparece antes de verbo (to book). Antes de substantivo, não use to.
Would you like some coffees?
Would you like a coffee?
Coffee no sentido de "um café" conta como singular: use a coffee, não some coffees.
