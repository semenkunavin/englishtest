Second Conditional: If I had more time, I would travel

O second conditional é usado para falar de situações imaginárias ou pouco prováveis no presente ou no futuro. A estrutura é if + past simple, seguida de would + verbo base. Você usa isso quando imagina: "se eu tivesse mais tempo, eu viajaria" — mas hoje não tenho.

  1. Estrutura básica: if + past simple, would + verbo base. Ex.: If I had more time, I would travel.
  2. Use o passado simples depois de if, mesmo falando do presente: If she lived in São Paulo, she would work at a big company.
  3. Com I, he, she e it, o verbo be aparece como were: If I were you, I would study English. (was é aceito na fala informal).
  4. A ordem pode inverter sem mudar o sentido: I would travel if I had more time. Quando if vem primeiro, use vírgula.
  5. Na negativa: wouldn't + verbo e didn't + verbo. Ex.: If Rafael didn't work on Saturdays, he wouldn't miss his capoeira class.
  6. Não use would na parte do if: If I would have time… está incorreto. Use could ou might no lugar de would para possibilidade: If I had money, I could visit Salvador.

Exemplos

  • If I had more time, I would travel around Brazil.Se eu tivesse mais tempo, eu viajaria pelo Brasil.
  • If Camila spoke better English, she would apply for a job at that multinational in São Paulo.Se a Camila falasse melhor inglês, ela se candidataria a uma vaga naquela multinacional em São Paulo.
  • If I were you, I would practice English for ten minutes every day.Se eu fosse você, eu praticaria inglês dez minutos todos os dias.
  • We would move to Florianópolis if we found good jobs there.Nós nos mudaríamos para Florianópolis se encontrássemos bons empregos lá.
  • If Thiago didn't work on Saturdays, he would take that online course.Se o Thiago não trabalhasse aos sábados, ele faria aquele curso on-line.
  • If I had a bigger budget, I could take a trip to Recife next month.Se eu tivesse um orçamento maior, eu poderia fazer uma viagem a Recife no mês que vem.

Erros típicos

If I would have more time, I would travel.
If I had more time, I would travel.
Depois de if no second conditional usa-se o passado simples, nunca would.
If I had more time, I will travel.
If I had more time, I would travel.
A segunda parte pede would + verbo, não will, porque a situação é imaginária.
If I had more time, I would traveled.
If I had more time, I would travel.
Depois de would o verbo fica na forma base, sem -ed.

Teste você mesmo

  1. If I ___ more free time, I would take a trip to Salvador.

  2. If Mariana lived in Rio, she ___ English every day.

  3. If he ___ his English, he would apply for a job at a multinational.

  4. I would study abroad if my parents ___ more money.

  5. If I ___ you, I would start an English course today.
