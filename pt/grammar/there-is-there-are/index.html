There is / There are: como usar em inglês

Use there is e there are para dizer que algo existe ou está em um lugar: There is a hotel near the airport. É uma estrutura essencial para viagens, reuniões e e-mails de trabalho, e é diferente de ter em português: não se diz "tem um hotel", mas there is a hotel.

  1. Use there is com substantivo singular ou incontável: There is a bank on Rua Augusta. / There is water in the fridge.
  2. Use there are com substantivo plural: There are two flights to Miami today.
  3. Negativa: there isn't (singular) e there aren't (plural): There isn't a metro station here. / There aren't any vacancies.
  4. Pergunta: inverta a ordem — Is there...? e Are there...?: Is there a Wi-Fi password? / Are there tickets for Friday?
  5. Passado: there was (singular) e there were (plural): There was a meeting yesterday. / There were 20 candidates.
  6. Não traduza "tem" do português como have: use there is / there are para existência. There is a problem = "Tem um problema".
  7. Com any em negativas e perguntas plurais, não use a: Are there any questions?

Exemplos

  • There is a job opening at the São Paulo office.Tem uma vaga de emprego no escritório de São Paulo.
  • There are three meetings on Monday.Tem três reuniões na segunda-feira.
  • Is there a charger in your bag?Tem um carregador na sua mochila?
  • There aren't any direct flights to Lisbon today.Não tem nenhum voo direto para Lisboa hoje.
  • There was a delay at Guarulhos airport.Houve um atraso no aeroporto de Guarulhos.
  • Are there any hotels near the beach in Rio?Tem hotéis perto da praia no Rio?

Erros típicos

Have a hotel near the airport.
There is a hotel near the airport.
Para existência, o inglês usa there is / there are, não have.
There is many candidates for the job.
There are many candidates for the job.
Candidates é plural, então use there are.
Is there any question?
Are there any questions?
Com plural (questions), use are there.

Teste você mesmo

  1. There ___ a bus stop in front of the hotel.

  2. There ___ two restaurants near the office.

  3. ___ there a doctor on the team?

  4. There ___ any tickets for the flight to Salvador.

  5. ___ there any questions about the project?
