Zero Conditional em inglês: If you heat ice, it melts

O zero conditional é a estrutura que usamos para falar de verdades gerais, fatos científicos e rotinas: coisas que sempre acontecem quando uma condição é cumprida. Use if + present simple na condição e present simple no resultado. É essencial para o trabalho (explicar procedimentos, regras, processos) e para viagens (regras, horários e costumes em outro país).

  1. Estrutura: If + present simple, present simple. Exemplo: If you study every day, you learn faster.
  2. Use when no lugar de if quando quiser dizer "sempre que": When I travel, I always take my passport. O sentido continua zero conditional.
  3. A ordem das partes pode mudar: Water boils if you heat it to 100°C. Só não esqueça: com if no início, use vírgula antes da segunda parte.
  4. Não use will nem would em nenhuma das partes: o zero conditional fala do que é sempre verdade, não de um futuro específico.
  5. Com if, a condição vem antes do resultado; com unless ("a menos que"), use a mesma estrutura: Unless you practice, you don't improve.
  6. Use para instruções e procedimentos no trabalho: If the client calls, write down the name and the order number.

Exemplos

  • If you heat ice, it melts.Se você aquece o gelo, ele derrete.
  • When Júlia travels to Recife for work, she always packs a light jacket for the plane.Quando Júlia viaja para Recife a trabalho, ela sempre leva um casaco leve para o avião.
  • If a menu is in English, Rafael translates it for the whole team.Se um menu está em inglês, Rafael traduz para a equipe inteira.
  • Plants don't grow if they don't get sunlight.As plantas não crescem se não recebem luz do sol.
  • If you press this button, the machine stops immediately.Se você aperta este botão, a máquina para imediatamente.
  • When Camila works in São Paulo, she takes the metro because traffic is terrible.Quando Camila trabalha em São Paulo, ela pega o metrô porque o trânsito é terrível.

Erros típicos

If you heat ice, it will melts.
If you heat ice, it melts.
Zero conditional usa present simple nas duas partes; will é para o first conditional, com situação possível no futuro.
If you will heat ice, it melts.
If you heat ice, it melts.
Nunca use will depois de if. A condição geral fica no present simple.
When I am tired, I will go to bed early.
When I am tired, I go to bed early.
Com when/if sobre hábito, o resultado também fica no present simple, não em will.

  2. When Larissa ___ to Salvador, she visits the old town.

  3. ___ you don't speak English, you use a translation app at the airport.

  4. The team leader writes a report if the client ___.
