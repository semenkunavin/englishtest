First Conditional em inglês: If it rains, I will stay home

O first conditional é a estrutura que você usa para falar de uma condição possível no futuro e do resultado dela: se algo acontecer, outra coisa vai acontecer. É muito comum em planos de viagem e de carreira, como If I pass the interview, I will start on Monday. Use quando a situação é realista, não é imaginação.

  1. A estrutura básica é if + present simple, depois will + verbo: If it rains, I will stay home.
  2. Na parte do if, nunca use will: diga If you study, não If you will study.
  3. A ordem das partes pode mudar: I will stay home if it rains. Se o if vem primeiro, use vírgula antes da segunda parte.
  4. Use will na segunda parte para o resultado: She will call you if she arrives early. Também pode usar can ou may quando o resultado não é certeza.
  5. O first conditional fala de situações reais e prováveis, não de sonhos impossíveis. Para o impossível, existe o second conditional (If I were rich...).
  6. Na parte do if, o verbo fica no presente simples, mesmo falando do futuro: If Juliana gets the visa, she will travel to Canada.

Exemplos

  • If it rains tomorrow, I will stay home in São Paulo.Se chover amanhã, eu vou ficar em casa em São Paulo.
  • If Rafael passes the test, he will apply for the job.Se o Rafael passar no teste, ele vai se candidatar ao emprego.
  • I will buy the tickets if the price is good.Eu vou comprar as passagens se o preço estiver bom.
  • If you study English every day, you will speak with confidence on your trip to Florianópolis.Se você estudar inglês todos os dias, vai falar com confiança na sua viagem a Florianópolis.
  • Camila will call the client if she finishes the report early.A Camila vai ligar para o cliente se terminar o relatório cedo.
  • If we save money this year, we will travel to Portugal in July.Se economizarmos dinheiro este ano, vamos viajar para Portugal em julho.

Erros típicos

If it will rain, I will stay home.
If it rains, I will stay home.
Depois de if usa-se o present simple, não will.
If I see Ana, I tell her the news.
If I see Ana, I will tell her the news.
A segunda parte precisa do will para mostrar o resultado futuro.
If he studies, he pass the exam.
If he studies, he will pass the exam.
Falta o will antes do verbo na parte do resultado.

Teste você mesmo

  1. If it ___ tomorrow, we will cancel the picnic.

  2. If you practice every day, you ___ the interview.

  3. I ___ you if I arrive early.

  4. If Juliana ___ the visa, she will travel to Canada.

  5. We will book the hotel if the price ___ good.
