Some و Any في الإنجليزية: شرح مبسط للمبتدئين

نستخدم some وany للتعبير عن كمية غير محددة، مثل «بعض» أو «أي». نستخدم some غالبًا في الجمل المثبتة، وany في النفي والسؤال. وسنوضح ذلك بأمثلة بسيطة بأسماء مثل أحمد وفاطمة ومدن مثل القاهرة والرياض.

  1. نستخدم some في الجمل المثبتة: I have some friends in Cairo.
  2. نستخدم any في النفي: Ahmed doesn’t have any brothers.
  3. نستخدم any في السؤال: Do you have any questions?
  4. نستخدم some في السؤال عند العرض أو الطلب: Would you like some tea?
  5. نستخدم some وany مع الأسماء الجمع أو غير المعدودة، لا مع المفرد المعدود: some water، any books.
  6. نستخدم any في الجمل المثبتة بمعنى «أي»: You can visit any museum in Riyadh.

أمثلة

  • Ahmed has some cousins in Cairo.لدى أحمد بعض أبناء العم في القاهرة.
  • Fatima doesn’t have any sisters.ليس لدى فاطمة أي أخوات.
  • Do you have any brothers in Riyadh?هل لديك أي إخوة في الرياض؟
  • We need some water, please.نحتاج بعض الماء من فضلك.
  • Would you like some tea, Fatima?هل ترغبين في بعض الشاي يا فاطمة؟
  • You can call any doctor in Cairo.يمكنك الاتصال بأي طبيب في القاهرة.

أخطاء شائعة

I have any friends in Riyadh.
I have some friends in Riyadh.
في الجملة المثبتة نستخدم some لا any.
Ahmed doesn’t have some brothers.
Ahmed doesn’t have any brothers.
في النفي نستخدم any لا some.
Do you have some books?
Do you have any books?
في السؤال العادي نستخدم any، ونستخدم some في العرض أو الطلب فقط.

اختبر نفسك

  1. Fatima has ___ money in her bag.

  2. Ahmed doesn’t have ___ time today.

  3. Do you have ___ questions about Cairo?

  4. Would you like ___ coffee, Ahmed?

  5. We need ___ books for the lesson.
