التعبير عن الطلب بأدب: Would like (I'd like a coffee)

التعبير would like يعني «أريد» لكنه أكثر أدبًا من want. نستعمله عند طلب شيء في مقهى أو مطعم، أو عند تقديم عرض بلطف لشخص آخر. الاختصار I'd like شائع جدًا في الكلام اليومي.

  1. بعد would like نضع اسمًا أو to + فعل، لا نضع الفعل المجرد: I'd like a coffee / I'd like to sit.
  2. الاختصار يكون مع الضمائر فقط: I'd like، you'd like، we'd like، they'd like، he'd like، she'd like.
  3. للسؤال عن رغبة الآخرين نقدّم would: Would you like tea? والجواب القصير: Yes, please. أو No, thank you.
  4. لا نقول I would like I go؛ الصواب I would like to go لأن to ضرورية قبل الفعل.
  5. مع would like نستخدم some في الإثبات وany في السؤال: I'd like some water. / Would you like any help?

أمثلة

  • I'd like a coffee, please.أريد قهوة، من فضلك.
  • Ahmed would like to visit Cairo next week.أحمد يريد زيارة القاهرة الأسبوع القادم.
  • Would you like some tea, Fatima?هل ترغبين في بعض الشاي يا فاطمة؟
  • We'd like a table for four in Riyadh.نريد طاولة لأربعة أشخاص في الرياض.
  • She'd like to learn English.هي تريد تعلّم الإنجليزية.
  • I'd like the bill, please.أريد الفاتورة، من فضلك.

أخطاء شائعة

I'd like go to Cairo.
I'd like to go to Cairo.
بعد would like يجب وضع to قبل الفعل.
I would like a coffee?
Would you like a coffee?
السؤال يبدأ بـWould وليس I would.
I like a coffee now.
I'd like a coffee now.
like وحدها تعني «أحب»، والطلب يحتاج would like.
