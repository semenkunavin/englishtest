أدوات الإشارة في الإنجليزية: this / that / these / those

أدوات الإشارة هي كلمات نستخدمها لنشير إلى شيء قريب أو بعيد. نستخدم this وthese للأشياء القريبة، وthat وthose للأشياء البعيدة. ونختار المفرد أو الجمع حسب عدد الأشياء التي نشير إليها.

  1. نستخدم this مع الاسم المفرد القريب: this book (هذا الكتاب).
  2. نستخدم these مع الاسم الجمع القريب: these books (هذه الكتب).
  3. نستخدم that مع الاسم المفرد البعيد: that car (تلك السيارة).
  4. نستخدم those مع الاسم الجمع البعيد: those cars (تلك السيارات).
  5. لا نضيف is أو are بعد أداة الإشارة إذا جاء بعدها اسم مباشرة: نقول this book وليس this is book.
  6. نستخدم is مع this وthat، وare مع these وthose: This is a pen. / These are pens.

أمثلة

  • This is Ahmed.هذا أحمد.
  • That is Fatima's bag.تلك حقيبة فاطمة.
  • These are my books in Cairo.هذه كتبي في القاهرة.
  • Those are tall buildings in Riyadh.تلك مباني عالية في الرياض.
  • This pen is new.هذا القلم جديد.
  • Are those your keys?هل تلك مفاتيحك؟

أخطاء شائعة

This books are new.
These books are new.
كلمة books جمع، لذلك نستخدم these وليس this.
Those is my friend.
That is my friend.
كلمة friend مفرد، فنستخدم that مع is.
This is book.
This is a book.
الاسم المفرد المعدود يحتاج أداة تنكير a بعد is.

اختبر نفسك

  1. ___ is my friend Ahmed.

  2. ___ are my books over there in Riyadh.

  3. ___ pen here is mine.

  4. ___ are Fatima's keys near you.

  5. ___ is the Cairo museum over there.
