الشرط الثاني: If I had more time, I would travel

الشرط الثاني (Second Conditional) نستخدمه للحديث عن موقف غير واقعي أو غير محتمل في الحاضر أو المستقبل، أو عن تخيّل ورغبة. نستخدم معه if + past simple في جملة الشرط، وwould + المصدر في جملة النتيجة. الجملة تدل على أن الوضع الآن مختلف عمّا نتخيّل.

  1. نكوّن الشرط من جزأين: If + past simple ثم would + base verb، مثل: If Fatima had a car, she would drive to Riyadh.
  2. الفعل be يأتي مع were مع جميع الضمائر في الأسلوب الرسمي: If I were you, I would study more.
  3. يمكن تقديم النتيجة أو الشرط، ولكن الفاصلة , توضع فقط إذا بدأت الجملة بـ If، مثل: Ahmed would buy a flat if he had enough money.
  4. لا نستخدم will في جملة الشرط، بل الماضي البسيط: نقول If I had time, I would visit Cairo.
  5. نستخدم could بدل would للحديث عن القدرة أو الإمكانية: If I had more time, I could travel with Ahmed to Cairo.
  6. الشرط الثاني لا يصف الماضي أبدًا، بل يصف تخيّلًا في الحاضر أو المستقبل: If I spoke Turkish, I would help you at the airport.

أمثلة

  • If Ahmed had more time, he would travel to Cairo.لو كان أحمد يملك مزيدًا من الوقت، لسافر إلى القاهرة.
  • Fatima would feel happier if she lived near her family in Riyadh.لو كانت فاطمة تسكن قرب عائلتها في الرياض، لشعرت بسعادة أكبر.
  • If I were you, I would talk to the teacher before the exam.لو كنت مكانك، لتحدّثت إلى المعلّم قبل الامتحان.
  • If we had a bigger flat, we would invite our friends every week.لو كان لدينا شقة أكبر، لدعونا أصدقاءنا كل أسبوع.
  • He could visit Cairo more often if he had a car.كان يستطيع أن يزور القاهرة كثيرًا لو كان عنده سيارة.
  • If it were not so hot, Fatima would walk to work in Riyadh.لو لم يكن الجو حارًّا إلى هذا الحد، لمشت فاطمة إلى العمل في الرياض.

أخطاء شائعة

If Ahmed will come, we would go to Cairo.
If Ahmed came, we would go to Cairo.
لا يُستعمل will في جملة الشرط؛ نستخدم الماضي البسيط came.
If I would have more time, I would travel.
If I had more time, I would travel.
لا يوضع would في جزء If، بل يدخل على النتيجة فقط.
If Fatima was here, she will help us.
If Fatima were here, she would help us.
في الشرط الثاني نستخدم were وwould، وليس was وwill.

اختبر نفسك

  1. If Ahmed ___ more time, he would travel to Cairo.

  2. If I ___ you, I would visit Riyadh.

  3. Fatima would buy the dress if she ___ enough money.

  4. If we lived in Cairo, we ___ see the Nile every day.

  5. If he ___ so busy, he could come to the meeting.
