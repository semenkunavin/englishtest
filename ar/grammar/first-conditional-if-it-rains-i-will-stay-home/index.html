الشرط الأول في الإنجليزية: First Conditional

الشرط الأول (First Conditional) تركيب نستخدمه للحديث عن احتمال حقيقي في المستقبل: إذا تحقق الشرط، فستكون النتيجة كذلك. نستخدمه في الوعود والتحذيرات والخطط، مثل: إذا أمطرت، سأبقى في البيت. الصيغة الأساسية هي: If + present simple, will + base verb.

  1. التركيب الأساسي: If + present simple, will + base verb، مثال: If it rains, I will stay home.
  2. بعد If لا نستخدم will أبداً؛ نستخدم المضارع البسيط حتى لو كان المعنى مستقبلياً: If Ahmed comes, we will eat.
  3. يمكن وضع جملة النتيجة أولاً ثم الشرط: I will stay home if it rains. لا نضع فاصلة قبل if في هذه الحالة.
  4. الفاعل في جملة If قد يكون I, you, he, she, it, we, they؛ الفعل يتبع المضارع البسيط: مع he/she/it نضيف -s: If Fatima calls, I will answer.
  5. النفي ممكن في الجزأين: If you do not hurry, you will miss the bus. وIf it rains, I will not go to Cairo.
  6. لا نستخدم will في جملة الشرط؛ فقط في جملة النتيجة: If we go to Riyadh, we will visit the museum.

أمثلة

  • If it rains, I will stay home.إذا أمطرت، سأبقى في البيت.
  • If Ahmed studies hard, he will pass the exam.إذا درس أحمد بجد، سينجح في الامتحان.
  • Fatima will call you if she arrives early.ستتصل بك فاطمة إذا وصلت مبكراً.
  • If we go to Cairo, we will visit the pyramids.إذا ذهبنا إلى القاهرة، سنزور الأهرامات.
  • If you do not hurry, you will miss the bus.إذا لم تسرع، ستفوتك الحافلة.
  • If the weather is good, we will travel to Riyadh.إذا كان الطقس جيداً، سنسافر إلى الرياض.

أخطاء شائعة

If it will rain, I will stay home.
If it rains, I will stay home.
لا نستخدم will بعد If؛ نستخدم المضارع البسيط rains.
If Ahmed come, we will eat.
If Ahmed comes, we will eat.
مع he/she/it نضيف -s للفعل في المضارع البسيط: comes.
If she calls, I answer her.
If she calls, I will answer her.
جملة النتيجة تحتاج will + base verb، لا المضارع البسيط.
