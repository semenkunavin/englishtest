So و such في الإنجليزية: شرح مبسّط للمستوى B1

نستخدم so وsuch للتعبير عن المبالغة والتأكيد في الإنجليزية. تأتي so قبل الصفة أو الظرف، وتأتي such قبل الاسم (غالبًا مع صفة). نستخدمهما كثيرًا في الكلام اليومي للتعبير عن الإعجاب أو الاندهاش.

  1. نستخدم so + adjective/adverb: مثل so tired وso quickly، ولا نضع بعدها اسمًا.
  2. نستخدم such + (a/an) + adjective + noun: مثل such a nice day وsuch beautiful flowers.
  3. مع الاسم الجمع أو غير المعدود لا نضع a/an بعد such: such good friends وsuch terrible weather.
  4. نستخدم so much / so many مع الكمية: so many books وso much time.
  5. نستخدم so ... that وsuch ... that للتعبير عن النتيجة: She was so tired that she slept early.
  6. لا نقول so a nice day، بل such a nice day، لأن so لا تأتي قبل الاسم.

أمثلة

  • Ahmed was so tired that he went to bed early.كان أحمد متعبًا جدًا لدرجة أنه نام مبكرًا.
  • Fatima is such a kind teacher.فاطمة معلمة لطيفة جدًا.
  • Cairo was so hot last summer.كانت القاهرة حارة جدًا الصيف الماضي.
  • They are such good friends.هم أصدقاء جيدون جدًا.
  • He drives so quickly in Riyadh.هو يقود بسرعة كبيرة في الرياض.
  • It was such beautiful weather that we stayed outside.كان الطقس جميلًا جدًا لدرجة أننا بقينا في الخارج.

أخطاء شائعة

Ahmed is so a good student.
Ahmed is such a good student.
so لا تأتي قبل الاسم؛ نستخدم such a مع الاسم المفرد المعدود.
They are such nice people that everyone likes them.
هم أناس لطفاء جدًا لدرجة أن الجميع يحبهم.
هذه الجملة صحيحة نحويًا؛ الخطأ الشائع هو حذف such قبل الاسم.
Cairo is such hot in summer.
Cairo is so hot in summer.
الكلمة hot صفة بلا اسم بعدها، لذلك نستخدم so وليس such.
