First conditional en inglés: If it rains, I will stay home

El first conditional sirve para hablar de situaciones futuras que son posibles o probables, y de sus consecuencias. Se usa mucho para planes de trabajo y de viaje. Su estructura es if + presente simple, y luego will + verbo.

  1. Estructura básica: If + present simple, + will + verbo base. Ejemplo: If it rains, I will stay home.
  2. En la parte del if no se usa will: se usa el present simple (if it rains, no if it will rain).
  3. El orden de las partes es flexible: I will stay home if it rains. Si el if va primero, se pone coma después de la condición.
  4. Puedes usar won't en la consecuencia para hablar de lo que no pasará: If I don't finish the report, I won't go to the gym.
  5. Con will no se cambia el verbo: siempre va en forma base (will stay, no will stays).
  6. La condición puede ser negativa: If we don't leave early, we will miss the bus.

Ejemplos

  • If it rains tomorrow, I will work from home.Si mañana llueve, trabajaré desde casa.
  • If I finish the report early, I will call you.Si termino el informe temprano, te llamaré.
  • If we save enough money, we will travel to Cartagena in December.Si ahorramos suficiente dinero, viajaremos a Cartagena en diciembre.
  • If Valeria gets the job in Monterrey, she will move next month.Si Valeria consigue el trabajo en Monterrey, se mudará el próximo mes.
  • We won't take a taxi if the metro is open.No tomaremos un taxi si el metro está abierto.
  • If you don't confirm the meeting, I will call Andrés.Si no confirmas la reunión, llamaré a Andrés.

Errores típicos

If it will rain, I will stay home.
If it rains, I will stay home.
En la parte del if se usa present simple, no will.
If she finish the project, she will travel to Lima.
If she finishes the project, she will travel to Lima.
Con she en present simple el verbo lleva -s: finishes.
If we arrive late, we will missed the flight.
If we arrive late, we will miss the flight.
Después de will el verbo va en forma base: miss.

Ponte a prueba

  1. If it ___, I will stay home.

  2. If Mateo ___ the report, he will send it to you.

  3. If we save money, we ___ to Bogotá.

  4. If the metro ___, we won't take a taxi.

  5. I will call Camila if the meeting ___ late.
