Some y any en inglés: cómo usarlos (nivel A1)

En inglés usamos some y any para hablar de cantidades indefinidas, sin decir un número exacto. Some se usa normalmente en oraciones afirmativas y any en negativas y preguntas. Es muy útil en el trabajo y en los viajes, por ejemplo para pedir información o hablar de lo que tienes y lo que no tienes.

  1. Usa some en oraciones afirmativas: I have some questions.
  2. Usa any en oraciones negativas: We don't have any milk.
  3. Usa any en la mayoría de las preguntas: Do you have any change?
  4. Usa some en preguntas cuando ofreces o pides algo: Would you like some coffee? y Can I have some water?
  5. Con sustantivos contables usa plural (some emails) y con incontables usa singular (some information).
  6. En respuestas cortas: Yes, I have some. / No, I don't have any.

Ejemplos

  • Mariana has some meetings in Bogotá this week.Mariana tiene algunas reuniones en Bogotá esta semana.
  • I don't have any questions about the report.No tengo ninguna pregunta sobre el informe.
  • Do you have any luggage, señor?¿Tiene usted algún equipaje, señor?
  • Can I have some water, please?¿Me puede dar un poco de agua, por favor?
  • There aren't any taxis at the airport in Lima right now.No hay ningún taxi en el aeropuerto de Lima ahora mismo.
  • Would you like some coffee before the meeting, Andrés?¿Quieres un poco de café antes de la reunión, Andrés?

Errores típicos

I don't have some money.
I don't have any money.
En oraciones negativas usamos any, no some.
Do you have some brothers?
Do you have any brothers?
En preguntas generales usamos any; some es para ofrecer o pedir.
She has any information about the flight.
She has some information about the flight.
En oraciones afirmativas usamos some.

Ponte a prueba

  1. Lucía has ___ friends in Santiago.

  2. We don't have ___ time before the flight.

  3. Do you need ___ help with the presentation?

  4. Would you like ___ tea, Carlos?

  5. There aren't ___ open shops near the hotel.
