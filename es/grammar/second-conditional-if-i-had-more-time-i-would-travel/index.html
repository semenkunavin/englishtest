Second conditional: If I had more time, I would travel

El second conditional se usa para hablar de situaciones imaginarias o poco probables en el presente o el futuro. Su estructura es If + past simple, y en la otra parte would + verbo base. Es muy común para expresar deseos, sueños y planes hipotéticos sobre el trabajo y los viajes.

  1. Estructura básica: If + past simple, subject + would + verb. Ejemplo: If I had more time, I would travel.
  2. En la parte con If no se usa would: se usa el past simple. Di If I had, no If I would have.
  3. Puedes invertir el orden: I would travel if I had more time. Si la parte con If va primero, usa coma.
  4. Con I, he, she, it el pasado de be suele ser were: If I were rich, I would travel more.
  5. Usa el second conditional para situaciones poco probables o imaginarias; para situaciones reales y posibles usa el first conditional (If I have time, I will travel).
  6. En inglés no existe el subjuntivo español aquí: If I had = «si tuviera / si tuviese». No traduzcas con would en la parte con If.

Ejemplos

  • If I had more time, I would travel around Latin America.Si tuviera más tiempo, viajaría por Latinoamérica.
  • If Marco worked less, he would go to the beach in Mancora.Si Marco trabajara menos, iría a la playa en Máncora.
  • I would learn English faster if I practiced every day.Aprendería inglés más rápido si practicara todos los días.
  • If Valeria spoke English, she would apply for a job in Panama.Si Valeria hablara inglés, postularía a un trabajo en Panamá.
  • We would visit Cartagena if the flight weren't so expensive.Visitaríamos Cartagena si el vuelo no fuera tan caro.
  • If I were you, I would save money for a trip to Oaxaca.Si yo fuera tú, ahorraría dinero para un viaje a Oaxaca.

Errores típicos

If I would have more time, I would travel.
If I had more time, I would travel.
En la parte con If se usa past simple, no would.
If I have more time, I would travel.
If I had more time, I would travel.
Para una situación imaginaria se usa past simple, no present simple.
If she studies more, she would get a better job.
If she studied more, she would get a better job.
En la parte con If del second conditional va el past simple: studied.

Ponte a prueba

  1. If I ___ more time, I would travel to Peru.

  2. If Diego worked less, he ___ more free time.

  3. I would visit Bogotá if the ticket ___ cheaper.

  4. If I ___ you, I would apply for that job in Chile.

  5. They would practice English every day if they ___ a good teacher.
