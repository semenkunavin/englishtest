There is / There are: aprende a describir en inglés

Usamos There is y There are para decir que algo existe o está presente en un lugar. Es muy útil para describir tu oficina, tu ciudad o un destino de viaje. There is se usa con singular y There are con plural.

  1. There is se usa con sustantivos singulares o incontables: There is a restaurant.
  2. There are se usa con sustantivos plurales: There are two banks.
  3. Para negar, usa There isn't o There aren't: There isn't a printer.
  4. Para preguntar, invierte: Is there...? o Are there...?: Are there any hotels?
  5. Usa some en afirmativo y any en negativo y preguntas: There are some chairs, There aren't any chairs.
  6. Respuestas cortas: Yes, there is / No, there isn't; Yes, there are / No, there aren't.

Ejemplos

  • There is a new coworking space in Miraflores.Hay un nuevo espacio de coworking en Miraflores.
  • There are three meetings this afternoon.Hay tres reuniones esta tarde.
  • There isn't a direct flight to Arequipa today.No hay un vuelo directo a Arequipa hoy.
  • There aren't any tickets for the night bus.No hay boletos para el autobús nocturno.
  • Is there a bank near the hotel?¿Hay un banco cerca del hotel?
  • Are there any vegetarian options on the menu?¿Hay opciones vegetarianas en el menú?

Errores típicos

There are a laptop on the desk.
There is a laptop on the desk.
Con sustantivo singular se usa There is, no There are.
There is two hotels in San José.
There are two hotels in San José.
Con sustantivo plural se usa There are, no There is.
There aren't some chairs in the room.
There aren't any chairs in the room.
En negativo se usa any, no some.

Ponte a prueba

  1. ___ a pharmacy near the office.

  2. ___ many tourists in Cartagena in December.

  3. ___ any milk for the coffee?

  4. There ___ a printer in the meeting room.

  5. ___ any buses to the airport at night?
