Would like (I'd like a coffee): pedir con cortesía en inglés

Usamos would like (forma corta I'd like) para pedir algo o expresar un deseo de manera educada: en un café, en un hotel o en una reunión de trabajo. Es más formal y amable que I want. También sirve para ofrecer cosas: Would you like...?

  1. Would like va seguido de un sustantivo o de to + verbo: I'd like a coffee, I'd like to book a room.
  2. La forma corta de would es 'd: I'd like, you'd like, we'd like. Con he, she e it: she'd like.
  3. En preguntas, would va antes del sujeto: Would you like some water? (ofrecer) y What would you like? (preguntar qué quiere alguien).
  4. Nunca uses would like con to be para pedir: para un objeto usa el sustantivo directo (I'd like the menu), no I'd like to the menu.
  5. Para la negativa: I wouldn't like + sustantivo o to + verbo: I wouldn't like a window seat.
  6. Después de Would you like, responde con Yes, please o No, thank you; no uses Yes, I like.

Ejemplos

  • I'd like a coffee, please.Quisiera un café, por favor.
  • Would you like to sit near the window?¿Le gustaría sentarse cerca de la ventana?
  • I'd like to book a room for two nights.Quisiera reservar una habitación por dos noches.
  • We'd like the bill, please.Nos gustaría la cuenta, por favor.
  • What would you like for breakfast?¿Qué le gustaría para el desayuno?
  • She'd like to visit Machu Picchu next year.A ella le gustaría visitar Machu Picchu el próximo año.

Errores típicos

I would like a coffee to.
I would like a coffee.
Tras a coffee no se usa to: to solo aparece antes de un verbo (to drink).
I'd like to the menu.
I'd like the menu.
Si pides un sustantivo, no pongas to: I'd like + sustantivo directamente.
Would you like a coffee? Yes, I like.
Would you like a coffee? Yes, please.
Para aceptar un ofrecimiento se responde Yes, please / No, thank you, no I like.

Ponte a prueba

  1. ___ like a glass of water, please.

  2. Would you like ___ the museum with us?

  3. We'd like ___ menu, please.

  4. What ___ you like, señor? — A sandwich, please.

  5. Would you like some tea? — No, ___.
