There is / There are: Easy Guide for A1 Learners

We use there is and there are to say that something exists or is in a place. Use there is with one thing (singular) and there are with many things (plural). We often use it to describe a room, a town or a picture.

  1. Use there is + one thing: There is a book on the table.
  2. Use there are + two or more things: There are two books on the table.
  3. Questions: put is or are before there: Is there a bank near here? Are there any chairs?
  4. Short answers: Yes, there is. / No, there isn't. Yes, there are. / No, there aren't.
  5. Negative: there isn't (singular) and there aren't (plural): There isn't a garden. There aren't any shops.
  6. Use there is / there are in the past too: There was a park. There were two cars.

Examples

  • There is a cat in the garden.There is one cat, singular, with there is.
  • There are three apples on the plate.Three apples is plural, so we use there are.
  • Is there a supermarket near your house?Question form: is + there for one thing.
  • Are there any students in the classroom?Question form: are + there for plural.
  • There isn't a TV in my bedroom.Negative singular: there isn't.
  • There were two small shops here in 2010.Past plural form: there were.

Typical mistakes

There are a book on the table.
There is a book on the table.
A book is singular, so use there is.
There is many people in the park.
There are many people in the park.
People is plural, so use there are.
Is there any chairs in the kitchen?
Are there any chairs in the kitchen?
Chairs is plural, so use are there in questions.

Check yourself

  1. ___ a big window in my room.

  2. ___ five books in my bag.

  3. ___ a bank near the station?

  4. ___ any milk in the fridge?

  5. ___ two dogs in the garden yesterday.
