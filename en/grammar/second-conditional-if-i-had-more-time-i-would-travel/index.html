Second Conditional: If I Had More Time, I Would Travel

The second conditional talks about imaginary or unlikely situations in the present or future. We use it to imagine things that are not true now, or things that are probably not going to happen. For example: If I had more time, I would travel.

  1. Use if + past simple in the condition: If I had more money, …
  2. Use would + base verb in the result: … I would buy a house.
  3. The order is flexible: I would travel if I had more time. Put a comma only when the if part comes first.
  4. With I / he / she / it, use were in formal English: If I were you, I would apologize.
  5. Do not use would in the if part. Use the past simple there.
  6. Meaning: the situation is unreal or unlikely, not a real possibility. Compare: If I win the lottery (first conditional, possible) and If I won the lottery (second conditional, imagined).

Examples

  • If I had more time, I would travel around the world.If I had more time, I would travel around the world.
  • She would be happier if she changed her job.She would be happier if she changed her job.
  • If we lived near the sea, we would swim every day.If we lived near the sea, we would swim every day.
  • If I were you, I would tell him the truth.If I were you, I would tell him the truth.
  • He would learn faster if he practised every day.He would learn faster if he practised every day.
  • What would you do if you found a wallet in the street?What would you do if you found a wallet in the street?

Typical mistakes

If I would have more time, I would travel.
If I had more time, I would travel.
Use the past simple after if, not would.
If I had more time, I will travel.
If I had more time, I would travel.
The result needs would + base verb, not will.
If I would be you, I would apologize.
If I were you, I would apologize.
Use were (not would be) after if for unreal situations.

Check yourself

  1. If I ___ more money, I would buy a new car.

  2. She would come to the party if you ___ her.

  3. If I were you, I ___ more carefully.

  4. We would go for a walk if it ___ raining.

  5. What ___ if you lost your phone?
