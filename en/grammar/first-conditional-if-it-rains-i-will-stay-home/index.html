First Conditional: If It Rains, I Will Stay Home (A2)

The first conditional talks about a possible future situation and its result. We use it when we think something may really happen. It is very common in everyday English for plans, promises, warnings and offers.

  1. Use if + present simple in the condition: If it rains, ...
  2. Use will + base verb in the result: ... I will stay home.
  3. The two parts can change order: If it rains, I will stay home. = I will stay home if it rains.
  4. When the if part comes first, put a comma after it.
  5. Do not use will after if: If it will rain is wrong.
  6. You can use may, might or can instead of will in the result: If you study, you can pass.

Examples

  • If it rains, I will stay home.If it rains, I will stay home.
  • If you study hard, you will pass the exam.If you study hard, you will pass the exam.
  • She will call you if she needs help.She will call you if she needs help.
  • If we leave now, we will catch the early train.If we leave now, we will catch the early train.
  • I will buy some bread if the shop is open.I will buy some bread if the shop is open.
  • If he does not hurry, he will miss the bus.If he does not hurry, he will miss the bus.

Typical mistakes

If it will rain, I will stay home.
If it rains, I will stay home.
After if we use the present simple, not will.
If it rains, I stay home tomorrow.
If it rains, I will stay home tomorrow.
The result about the future needs will + base verb.

Check yourself

  1. If it ___ tomorrow, we will cancel the picnic.

  2. If you finish your homework, you ___ watch TV.

  3. I will call you if I ___ late.

  4. If she ___ the bus, she will be late for work.

  5. We will go to the beach if the weather ___ good.
