Zero Conditional: If You Heat Ice, It Melts (B1 English)

The zero conditional describes things that are always true: facts, scientific laws and general habits. We use if (or when) with the present simple in both parts of the sentence. Because the result always happens, the meaning is close to 'whenever' or 'every time'.

  1. Form: If + present simple, present simple. Example: If you heat ice, it melts.
  2. You can put the result first: Ice melts if you heat it. The comma is only needed when if comes first.
  3. When can replace if with the same meaning: When I drink coffee, I can't sleep.
  4. Use the zero conditional for facts and general truths, not for one specific future situation.
  5. Both clauses stay in the present simple; do not use will in the result when you describe a general fact.
  6. If and when clauses never take will, even in other conditionals.

Examples

  • If you heat ice, it melts.If you heat ice, it melts.
  • If you mix red and blue, you get purple.If you mix red and blue, you get purple.
  • Plants die if they don't get enough water.Plants die if they don't get enough water.
  • When I drink coffee at night, I can't sleep.When I drink coffee at night, I can't sleep.
  • If you press this button, the machine stops.If you press this button, the machine stops.
  • My teacher gets angry if we are late.My teacher gets angry if we are late.

Typical mistakes

If you heat ice, it will melt.
If you heat ice, it melts.
For a general fact, use the present simple in both clauses, not will.
If you will heat ice, it melts.
If you heat ice, it melts.
Never use will after if in the zero conditional.
If you heat ice, it melt.
If you heat ice, it melts.
The result clause needs the third-person -s: it melts.

Check yourself

  1. If you ___ water to 100°C, it boils.

  2. When I ___ late, my boss gets angry.

  3. Ice ___ if you heat it.

  4. If you ___ red and yellow, you get orange.
