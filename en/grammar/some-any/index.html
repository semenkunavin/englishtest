Some and Any: Easy A1 Grammar Guide

We use some and any with plural nouns and uncountable nouns to talk about an amount that is not exact. Some is usual in positive sentences, and any is usual in negative sentences and questions. Some is also common in offers and requests.

  1. Use some in positive sentences: I have some apples. There is some milk.
  2. Use any in negative sentences: I don't have any apples. There isn't any milk.
  3. Use any in questions: Do you have any apples? Is there any milk?
  4. Use some in offers and requests, even in questions: Would you like some tea? Can I have some water?
  5. Use some and any with plural nouns (some books) and uncountable nouns (some water), not with singular countable nouns.
  6. In a question that expects the answer yes, we often use some: Is there some problem?

Examples

  • I need some bread from the shop.I need some bread from the shop.
  • There are some good films on TV tonight.There are some good films on TV tonight.
  • We don't have any money.We don't have any money.
  • Do you have any brothers or sisters?Do you have any brothers or sisters?
  • Would you like some coffee?Would you like some coffee?
  • She didn't buy any vegetables.She didn't buy any vegetables.

Typical mistakes

I have any questions.
I have some questions.
In a positive sentence we use some, not any.
Do you have some brothers?
Do you have any brothers?
In a normal question we use any.
I don't want some milk.
I don't want any milk.
In a negative sentence we use any.
