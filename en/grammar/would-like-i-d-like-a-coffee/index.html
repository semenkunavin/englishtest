Would Like: I'd Like a Coffee (A1 English)

We use would like to say what we want in a polite way. It is very common in cafés, shops, hotels and restaurants. I'd like is the short form of I would like.

  1. Use would like + noun: I'd like a coffee.
  2. Use would like + to + verb: I'd like to pay.
  3. Short forms: I'd like, you'd like, he'd like, she'd like, we'd like, they'd like.
  4. Questions: Would you like...? For offers, answer Yes, please. or No, thank you.
  5. Do not use do or don't with would like: say I wouldn't like tea, not I don't would like tea.
  6. After would like, use some in offers: Would you like some water?

Examples

  • I'd like a coffee, please.I'd like a coffee, please.
  • She'd like a glass of water.She'd like a glass of water.
  • Would you like some tea?Would you like some tea?
  • We'd like to sit near the window.We'd like to sit near the window.
  • They'd like two tickets for the museum.They'd like two tickets for the museum.
  • I'd like to pay now, please.I'd like to pay now, please.

Typical mistakes

I like a coffee, please.
I'd like a coffee, please.
I like means you enjoy something in general; I'd like means you want it now.
I'd like a coffee to drink now.
I'd like to drink a coffee now.
Use would like to + verb when you talk about an action.
Do you would like some tea?
Would you like some tea?
Do not use do with would like; make the question with Would first.
